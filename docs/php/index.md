# PHP & Laravel

::: info Coming soon
The PHP & Laravel port isn't released yet.
:::

It will be published on Packagist, and installed with:

```sh
composer require pg-momik/no-nepali-profanity
```

The PHP & Laravel port will use the same word lists and matching rules as the JavaScript package, so a piece of text
gets the same result in every language. That covers detecting and censoring, the language and strictness options,
and the checks that keep real names from being flagged.

## Until then

- The [JavaScript package](/js/) is available now.
- To help build the PHP & Laravel port, see [Contributing](/js/contributing), or open an issue on
  [GitHub](https://github.com/PG-Momik/no-nepali-profanity/issues).
